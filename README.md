# GalleryLight

A beautiful, modern Android app to play videos and project images from your gallery — with real playback speed, color effects, zoom/pan, and flashlight support.

## Features

- 🎬 Video player — ExoPlayer (Media3) with speed control (0.5x–2.0x), loop, and color effects
- 🖼️ Image projector — pick multiple images, swipe, zoom, pan, apply effects
- 🔦 Flashlight — safe on devices without flash
- ⚙️ Settings — auto-play, loop, default speed, default brightness
- 🌑 Modern dark UI — Material 3, edge-to-edge, target API 36

## Tech stack

- Kotlin 2.0
- Android Gradle Plugin 8.13
- Min SDK 24 · Target SDK 36
- Media3 / ExoPlayer
- Material Components 1.13
- Coil
